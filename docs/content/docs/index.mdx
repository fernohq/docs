Ferno captures the behavior that helps teams understand product usage, conversion, and drop-off. The SDKs support browser and server-side event collection with the same core event model.

## Choose an SDK

- Use the **Browser SDK** for actions and views that happen in the web client.
- Use the **Node SDK** for trusted server-side outcomes such as payment success, subscription state, and account changes.
- Use both when a user journey starts in the browser but is confirmed by the backend.

<Tip>
  Track behavior, not input. Event names can be specific about the workflow step without containing what the user typed.
</Tip>
